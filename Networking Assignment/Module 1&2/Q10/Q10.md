A DHCP (Dynamic Host Configuration Protocol) server automatically assigns IP addresses and network configuration parameters to devices in a network, reducing the need for manual configuration.

The process follows a 4-step cycle known as **DORA (Discover, Offer, Request, Acknowledge)**:

1. **Discover**  
   When a device connects to the network, it broadcasts a DHCP Discover message to find available DHCP servers.

2. **Offer**  
   The DHCP server responds with a DHCP Offer message, which includes an available IP address and configuration details such as subnet mask, gateway, and DNS.

3. **Request**  
   The device replies with a DHCP Request message, indicating that it accepts the offered IP address.

4. **Acknowledge**  
   The DHCP server sends a DHCP Acknowledgment, confirming the assignment. The device can now use the IP address.

The assigned IP address is given for a limited time called a **lease period**, after which the device must renew it to continue using the same address.

Overall, DHCP simplifies network management, prevents IP conflicts, and enables efficient allocation of IP addresses.
