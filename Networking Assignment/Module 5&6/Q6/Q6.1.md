# IP Address Classification and Default Subnet Masks

## Objective
To identify the class of given IP addresses, determine their default subnet masks, and specify the valid IP address range for each class.

---

## Introduction
IP addresses are categorized into different classes based on their first octet. This classification helps in defining the network and host portions of an IP address. The main classes used in networking are Class A, Class B, and Class C, each having a default subnet mask and a specific address range.

---

## Given IP Addresses

- 10.1.1.1  
- 172.16.5.10  
- 192.168.1.5  

---

## IP Address Classification

### 1. IP Address: 10.1.1.1

- First octet: 10  
- Range: 1 – 126  

**Class:** A  
**Default Subnet Mask:** 255.0.0.0  

---

### 2. IP Address: 172.16.5.10

- First octet: 172  
- Range: 128 – 191  

**Class:** B  
**Default Subnet Mask:** 255.255.0.0  

---

### 3. IP Address: 192.168.1.5

- First octet: 192  
- Range: 192 – 223  

**Class:** C  
**Default Subnet Mask:** 255.255.255.0  

---

## IP Address Class Ranges

### Class A
- Range: 1.0.0.0 to 126.255.255.255  
- Default Subnet Mask: 255.0.0.0  

---

### Class B
- Range: 128.0.0.0 to 191.255.255.255  
- Default Subnet Mask: 255.255.0.0  

---

### Class C
- Range: 192.0.0.0 to 223.255.255.255  
- Default Subnet Mask: 255.255.255.0  

---

## Summary Table

| IP Address     | Class   | Default Subnet Mask |
|---------------|--------|---------------------|
| 10.1.1.1      | Class A | 255.0.0.0           |
| 172.16.5.10   | Class B | 255.255.0.0         |
| 192.168.1.5   | Class C | 255.255.255.0       |

---

## Conclusion
The classification of IP addresses is based on the value of the first octet. Class A, B, and C networks differ in their address ranges and default subnet masks, which determine how the network and host portions are divided. Understanding these classes is essential for designing and managing IP networks efficiently.
