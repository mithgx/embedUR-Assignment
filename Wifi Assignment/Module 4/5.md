# Client Association Process

The client association process establishes a connection between a wireless client and an Access Point.

Steps involved:

1. Scanning
   Client discovers available networks using passive or active scanning.

2. Authentication
   Client performs authentication with the AP. In modern networks, this is usually **Open System Authentication** (a basic exchange before security setup).

3. Association
   The client sends an **Association Request** containing capabilities (supported rates, security, QoS). The AP responds with an **Association Response**, assigning an Association ID (AID).

4. Security Setup
   If the network is secured (WPA2/WPA3), the authentication continues with higher-layer protocols like 802.1X/EAP or pre-shared key methods.

5. Data Transfer
   Once association and security are complete, normal data communication begins.

This process ensures compatibility, capability negotiation, and controlled access to the network.
