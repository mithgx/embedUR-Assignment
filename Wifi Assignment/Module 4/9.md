# Block ACK Mechanism

Block Acknowledgment (Block ACK) is an efficiency feature in 802.11n and later standards that allows multiple frames to be acknowledged using a single ACK frame.

Instead of sending an ACK for each frame:

* Sender transmits a burst of frames (frame aggregation)
* Receiver responds with a **Block ACK**, indicating which frames were successfully received using a bitmap

Types:

* Immediate Block ACK → sent immediately after transmission
* Delayed Block ACK → sent later (less common)

Advantages:

* Reduces control overhead (fewer ACK frames)
* Improves throughput
* Enables efficient retransmission (only lost frames are resent)
* Works well with frame aggregation (A-MPDU)

This mechanism is essential for high-throughput WLAN performance.
