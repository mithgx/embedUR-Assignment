# Medium Access Control Methodologies

Wi-Fi uses contention-based and controlled access mechanisms to share the wireless medium.

1. DCF (Distributed Coordination Function)

   * Default method using **CSMA/CA**
   * Devices sense channel, wait for idle, then transmit
   * Uses random backoff to avoid collisions
   * Supports ACK and retransmissions

2. PCF (Point Coordination Function)

   * Centralized polling by AP
   * Rarely implemented in real deployments

3. HCF (Hybrid Coordination Function)
   Introduced in 802.11e for QoS support:

   * EDCA (Enhanced Distributed Channel Access)
     Priority-based access using different queues (voice, video, best effort, background)

   * HCCA (HCF Controlled Channel Access)
     Centralized scheduling by AP (rare in practice)

Overall:

* DCF → basic contention-based access
* EDCA → prioritized traffic handling (widely used)
* PCF/HCCA → theoretical/limited real-world use
