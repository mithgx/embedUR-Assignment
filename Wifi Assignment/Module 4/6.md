# EAPOL 4-Way Handshake and Key Derivation

The EAPOL 4-way handshake is used in WPA2/WPA3 to establish secure encryption keys between the client (supplicant) and Access Point (authenticator).

Purpose:

* Derive encryption keys
* Confirm both parties share the same master key (PMK)
* Establish secure communication

Steps:

1. Message 1 (AP → Client)
   The AP sends a random number called **ANonce**. This initiates key generation.

2. Message 2 (Client → AP)
   The client generates its own random number (**SNonce**) and computes the **PTK (Pairwise Transient Key)** using:

   * PMK (from PSK or 802.1X)
   * ANonce, SNonce
   * MAC addresses
     The client sends SNonce and a MIC (Message Integrity Code) to the AP.

3. Message 3 (AP → Client)
   The AP also computes PTK and verifies the MIC. It then sends:

   * **GTK (Group Temporal Key)** for broadcast/multicast traffic
   * Encrypted using PTK
   * Includes installation instructions

4. Message 4 (Client → AP)
   Client acknowledges and installs keys. Secure communication begins.

Key Types:

* PMK → Master key (derived earlier)
* PTK → Used for unicast encryption (client ↔ AP)
* GTK → Used for broadcast/multicast traffic

This handshake ensures mutual authentication and secure key establishment without transmitting keys directly over the air.
