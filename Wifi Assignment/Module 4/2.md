# 802.11 MAC Frame Format

An 802.11 MAC frame consists of multiple fields, each serving a specific purpose in communication.

General structure:

| Field                | Size     | Purpose                                                      |
| -------------------- | -------- | ------------------------------------------------------------ |
| Frame Control        | 2 bytes  | Defines frame type, subtype, flags (To/From DS, retry, etc.) |
| Duration/ID          | 2 bytes  | Indicates medium reservation time (NAV)                      |
| Address 1            | 6 bytes  | Receiver MAC address                                         |
| Address 2            | 6 bytes  | Transmitter MAC address                                      |
| Address 3            | 6 bytes  | BSSID or destination depending on context                    |
| Sequence Control     | 2 bytes  | Sequence number + fragment number                            |
| Address 4 (optional) | 6 bytes  | Used in WDS (wireless distribution system)                   |
| Frame Body           | Variable | Payload (data or management info)                            |
| FCS                  | 4 bytes  | Error detection (CRC)                                        |

Important notes:

* Address fields vary depending on To DS / From DS bits
* Sequence control ensures proper ordering and retransmission handling
* FCS detects transmission errors

This flexible structure supports different frame types and network topologies.
