# Frame Aggregation: A-MSDU and A-MPDU

Frame aggregation improves efficiency by combining multiple frames into a single transmission.

1. A-MSDU (Aggregated MAC Service Data Unit)

   * Combines multiple MSDUs into one MPDU
   * Single MAC header for entire aggregate
   * Less overhead but less robust (error affects whole frame)

2. A-MPDU (Aggregated MAC Protocol Data Unit)

   * Combines multiple MPDUs into one transmission
   * Each MPDU has its own MAC header and FCS
   * More robust (individual MPDUs can be retransmitted)

3. A-MSDU within A-MPDU

   * Hybrid approach
   * Multiple MSDUs are first aggregated into MPDUs (A-MSDU)
   * Then multiple MPDUs are aggregated into A-MPDU
   * Maximizes efficiency while maintaining reliability

Comparison:

| Feature        | A-MSDU      | A-MPDU     |
| -------------- | ----------- | ---------- |
| Aggregation    | MSDU level  | MPDU level |
| Reliability    | Low         | High       |
| Overhead       | Low         | Higher     |
| Retransmission | Whole frame | Per MPDU   |

Modern Wi-Fi uses A-MPDU (often with A-MSDU inside) to achieve high throughput.
