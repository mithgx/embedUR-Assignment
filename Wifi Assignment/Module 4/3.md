# MAC Layer Functionalities

The MAC layer functionalities in Wi-Fi are categorized into Management, Control, and Data planes.

1. Management Plane
   Handles network setup, maintenance, and client lifecycle.

* Beaconing (advertising network)
* Authentication and deauthentication
* Association and reassociation
* Scanning (active/passive)
* Roaming support
* Probe request/response handling

2. Control Plane
   Ensures reliable and efficient use of the wireless medium.

* ACK (acknowledgment frames)
* RTS/CTS (collision avoidance)
* NAV (Network Allocation Vector management)
* Retransmission handling
* Power-saving coordination (PS-Poll, U-APSD)

3. Data Plane
   Responsible for actual data transmission.

* Data frame delivery
* Frame aggregation (A-MPDU, A-MSDU)
* Fragmentation and reassembly
* QoS handling (WMM, traffic prioritization)
* Encryption and decryption (WPA2/WPA3)

These functionalities together ensure efficient, reliable, and secure communication over the shared wireless medium.
