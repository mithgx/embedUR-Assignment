# Power Saving Mechanisms in MAC Layer

Power saving in the 802.11 MAC layer allows client devices to conserve battery by reducing active radio time while still maintaining connectivity.

Basic Mechanism (Legacy Power Save):

* Client notifies AP it is entering **Power Save (PS) mode**
* AP buffers frames for the sleeping client
* AP indicates buffered data using **Traffic Indication Map (TIM)** in Beacon frames
* Client wakes periodically, checks TIM, and retrieves data using **PS-Poll** frames

Types of Power Saving Mechanisms:

1. Legacy Power Save
   Uses PS-Poll to request buffered frames. Simple but inefficient due to overhead.

2. U-APSD (Unscheduled Automatic Power Save Delivery)
   Client triggers AP to send buffered frames by sending a trigger frame.

   * Reduces control overhead
   * Used in QoS/WMM networks (common in smartphones)

3. TWT (Target Wake Time – 802.11ax)
   AP schedules specific wake-up times for clients.

   * Highly efficient for IoT and dense networks
   * Minimizes contention and idle listening

Power-saving mechanisms balance energy efficiency with latency and throughput requirements.
