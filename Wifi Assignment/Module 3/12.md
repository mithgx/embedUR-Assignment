# Data Rate Calculation in Wi-Fi

Wi-Fi data rate depends on multiple PHY parameters including modulation, coding rate, channel bandwidth, number of spatial streams, and guard interval.

General formula:

Data Rate = (Bits per Symbol × Coding Rate × Number of Subcarriers × Spatial Streams) / Symbol Duration

Key factors:

* Modulation (Bits per Symbol)
  BPSK = 1, QPSK = 2, 16-QAM = 4, 64-QAM = 6, 256-QAM = 8, 1024-QAM = 10

* Coding Rate
  Typically 1/2, 2/3, 3/4, or 5/6 (higher rate → less redundancy, higher throughput)

* Channel Bandwidth
  20 MHz, 40 MHz, 80 MHz, 160 MHz (wider → more subcarriers)

* Spatial Streams
  More streams → higher throughput (MIMO)

* Guard Interval
  Short GI increases data rate by reducing symbol time

Example:
In 802.11ac with 80 MHz, 256-QAM, 5/6 coding, and 2 spatial streams → data rate can exceed 800 Mbps.

Wi-Fi dynamically adjusts these parameters (rate adaptation) based on channel conditions to balance throughput and reliability.
