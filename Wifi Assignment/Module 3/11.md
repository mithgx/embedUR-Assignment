# Types of PPDU Across Wi-Fi Generations

PPDU formats have evolved with different Wi-Fi standards to support higher data rates and advanced features.

1. Legacy PPDU (802.11a/b/g)
   Contains basic preamble and header fields. Supports single antenna transmission and simple modulation schemes.

2. HT PPDU (802.11n)
   Introduces High Throughput (HT) fields. Supports MIMO, channel bonding (40 MHz), and higher data rates.

3. VHT PPDU (802.11ac)
   Adds Very High Throughput (VHT) fields. Supports wider channels (80/160 MHz), higher modulation (256-QAM), and MU-MIMO.

4. HE PPDU (802.11ax)
   High Efficiency (HE) format introduces OFDMA, improved MU-MIMO, and 1024-QAM. Includes trigger-based and multi-user formats.

General PPDU Structure Evolution:

* Legacy → basic preamble + header + data
* HT → adds HT-specific signaling fields
* VHT → adds bandwidth and MU-MIMO signaling
* HE → adds OFDMA resource allocation and multi-user scheduling

Each generation extends the PHY header to carry more information required for advanced transmission techniques.
