# MIMO vs MU-MIMO

MIMO (Multiple Input Multiple Output) and MU-MIMO (Multi-User MIMO) are techniques that use multiple antennas to improve wireless performance.

MIMO
In MIMO, multiple antennas are used to transmit multiple spatial streams to a single user. This increases data rate and reliability for that user.

MU-MIMO
In MU-MIMO, the access point transmits separate spatial streams to multiple users simultaneously, improving overall network capacity.

Key differences:

| Feature         | MIMO (SU-MIMO)       | MU-MIMO                        |
| --------------- | -------------------- | ------------------------------ |
| Users served    | One user at a time   | Multiple users simultaneously  |
| Throughput gain | Per-user improvement | Network-wide improvement       |
| Complexity      | Lower                | Higher (requires coordination) |
| Used in         | 802.11n/ac/ax        | 802.11ac (downlink), 802.11ax  |

MIMO improves individual link performance, while MU-MIMO improves overall system efficiency, especially in multi-user environments.
