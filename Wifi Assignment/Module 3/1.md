# 802.11 PHY Layer Standards and Comparison

IEEE 802.11 defines multiple PHY layer standards that differ in frequency band, modulation, and data rates.

| Standard | Band        | Max Data Rate | Modulation       | Key Features                         |
| -------- | ----------- | ------------- | ---------------- | ------------------------------------ |
| 802.11b  | 2.4 GHz     | 11 Mbps       | DSSS (CCK)       | Long range, high interference        |
| 802.11a  | 5 GHz       | 54 Mbps       | OFDM             | Less interference, shorter range     |
| 802.11g  | 2.4 GHz     | 54 Mbps       | OFDM             | Backward compatible with 11b         |
| 802.11n  | 2.4/5 GHz   | 600 Mbps      | OFDM + MIMO      | Channel bonding, spatial streams     |
| 802.11ac | 5 GHz       | ~6.9 Gbps     | OFDM (256-QAM)   | Wider channels (80/160 MHz), MU-MIMO |
| 802.11ax | 2.4/5/6 GHz | ~9.6 Gbps     | OFDMA (1024-QAM) | Better efficiency, low latency       |

Key observations:

* Evolution increases throughput via higher-order modulation and wider channels
* MIMO and OFDMA significantly improve spectral efficiency
* Higher frequencies → higher speed but lower range
* Newer standards focus more on efficiency than just peak speed
