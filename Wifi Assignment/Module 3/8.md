# OFDM vs OFDMA

OFDM (Orthogonal Frequency Division Multiplexing) and OFDMA (Orthogonal Frequency Division Multiple Access) are closely related but differ in how subcarriers are allocated.

OFDM
In OFDM, all subcarriers are assigned to a single user at a time. One device uses the entire channel bandwidth during transmission.

OFDMA
In OFDMA, subcarriers are divided into smaller groups called Resource Units (RUs), allowing multiple users to transmit or receive simultaneously within the same channel.

Key differences:

| Feature     | OFDM                    | OFDMA                         |
| ----------- | ----------------------- | ----------------------------- |
| User access | Single user per time    | Multiple users simultaneously |
| Efficiency  | Lower in dense networks | Higher in dense environments  |
| Latency     | Higher contention delay | Reduced latency               |
| Used in     | 802.11a/g/n/ac          | 802.11ax (Wi-Fi 6)            |

OFDMA significantly improves efficiency and performance in high-density scenarios like campuses and stadiums.
