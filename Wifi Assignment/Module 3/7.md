# Structure of 802.11 PHY Layer Frame

An 802.11 PHY frame (PPDU – PLCP Protocol Data Unit) consists of two main parts: **Preamble**, **Header**, and **Payload**.

1. Preamble
   The preamble is used for synchronization and channel estimation. It allows the receiver to detect the signal, lock frequency/phase, and prepare for decoding. It includes training sequences (short and long training fields).

2. PHY Header (PLCP Header)
   Contains transmission parameters such as data rate, modulation scheme, length of payload, and coding information. This helps the receiver correctly interpret the incoming data.

3. Payload (PSDU)
   This carries the actual MAC frame (MPDU). It includes higher-layer data such as IP packets encapsulated inside 802.11 MAC frames.

Key purpose:

* Preamble → synchronization
* Header → decoding information
* Payload → actual data

Modern standards (802.11n/ac/ax) extend this structure with additional fields for MIMO, channel width, and advanced signaling.
