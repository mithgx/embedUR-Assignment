# Lightweight APs vs Cloud-based APs

Lightweight APs (LAPs) operate in a controller-based architecture where most control and management functions are handled by an on-premises Wireless LAN Controller (WLC). The AP primarily handles real-time RF operations, while configuration, authentication, and policy enforcement are centralized in the controller using protocols like CAPWAP.

Cloud-based APs, in contrast, are managed via a cloud controller hosted over the internet. The AP connects to the cloud platform for configuration, monitoring, and analytics. However, client data traffic is usually locally switched (does not always traverse the cloud), depending on the vendor design.

Key differences:

* Control Location: On-prem WLC (LAP) vs Cloud platform (Cloud AP)
* Deployment: Requires local controller vs no on-site controller
* Scalability: Limited by controller capacity vs highly scalable via cloud
* Management: Local management vs remote centralized dashboard
* Dependency: LAP depends on WLC availability; Cloud AP depends on internet/cloud reachability

Cloud APs are preferred for distributed environments (retail, branch offices), while LAPs are common in enterprise campuses requiring strict local control.
