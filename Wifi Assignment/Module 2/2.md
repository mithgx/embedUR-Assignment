# CAPWAP Protocol and Flow

CAPWAP (Control and Provisioning of Wireless Access Points) is a standard protocol that enables communication between lightweight APs and a Wireless LAN Controller (WLC).

The CAPWAP workflow consists of multiple stages:

1. Discovery
   The AP discovers available controllers using DHCP options, DNS resolution, broadcast, or static configuration.

2. Join
   The AP establishes a connection with the selected controller. Authentication occurs, typically using certificates.

3. DTLS Setup
   A secure channel is created using DTLS (Datagram TLS) to protect control communication.

4. Configuration
   The controller pushes configuration parameters such as SSID, VLAN mapping, security settings, and RF profiles.

5. Run Phase (Operational Phase)
   The AP becomes operational and starts forwarding client traffic and exchanging control messages via CAPWAP tunnels.

CAPWAP enables centralized provisioning, monitoring, and management of multiple APs, making it essential for scalable enterprise Wi-Fi architectures.
