# AP Mode Selection when WLC is in WAN

When the Wireless LAN Controller (WLC) is deployed across a WAN, **FlexConnect mode (also called H-REAP)** is the preferred AP mode.

In FlexConnect mode, the AP maintains CAPWAP control communication with the WLC over WAN but **locally switches client data traffic** to the local LAN instead of tunneling it to the controller. This avoids sending user traffic over WAN links, reducing latency and bandwidth consumption.

Key advantages:

* Local data forwarding → better performance and reduced WAN load
* Continued client connectivity even if WAN/WLC is unreachable
* Centralized configuration still possible via WLC
* Supports local authentication (optional, depending on setup)

This mode is ideal for branch offices or remote sites where WAN reliability and bandwidth are limited.
