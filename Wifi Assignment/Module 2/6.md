# Sniffer Mode vs Monitor Mode

Sniffer mode and Monitor mode are both used for analyzing wireless traffic, but they serve different purposes and operate differently.

Monitor Mode
In monitor mode, a Wi-Fi interface captures all wireless frames on a specific channel without associating to any Access Point. It provides raw 802.11 frames, including management, control, and data frames. This mode is commonly used with tools like Wireshark for packet-level analysis.

Use cases:

* Packet capture and protocol analysis
* Troubleshooting connectivity issues
* Security analysis (e.g., handshake capture)

Sniffer Mode
Sniffer mode is typically a vendor-specific implementation (especially in enterprise APs) where the AP captures traffic and forwards it to a remote analysis tool or server. It may include filtering and centralized capture capabilities.

Use cases:

* Remote troubleshooting in enterprise networks
* Centralized packet capture without physical access
* Monitoring client behavior across multiple APs

Key difference:

* Monitor mode is local and interface-based
* Sniffer mode is centralized and often controller/AP-assisted

Both are critical for debugging and analyzing Wi-Fi networks at the packet level.
