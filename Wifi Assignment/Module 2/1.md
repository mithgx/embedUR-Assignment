# SplitMAC Architecture

SplitMAC is an architecture where MAC layer responsibilities are divided between the Access Point (AP) and a centralized Wireless LAN Controller (WLC).

The AP handles **time-sensitive, real-time operations**, including frame transmission/reception, ACK handling, beacon generation, and encryption/decryption. These are latency-critical and must remain close to the radio hardware.

The controller handles **non-real-time MAC functions**, such as authentication (802.1X), association management, roaming coordination, QoS enforcement, RF management, and policy control.

This improves AP performance because:

* AP hardware remains lightweight (less CPU/memory required)
* Centralized processing enables better scalability and easier management
* Roaming is faster since decisions are coordinated centrally
* Network-wide policies (security, QoS) are consistently enforced

SplitMAC is commonly used in enterprise Wi-Fi deployments where centralized control is required.
