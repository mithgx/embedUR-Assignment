# Target Wake Time (TWT) in Wi-Fi 6

Target Wake Time (TWT) is a power-saving mechanism introduced in Wi-Fi 6 that allows devices to negotiate specific wake-up schedules with the Access Point.

How it works:

* AP and client agree on specific times for communication
* Client sleeps when not scheduled
* Wakes only at predefined intervals to send/receive data

Benefits for IoT devices:

* **Significant power savings** → longer battery life
* **Reduced contention** → fewer devices competing at the same time
* **Improved efficiency** → scheduled transmissions instead of random access
* **Scalability** → supports large number of low-power devices

Example:
An IoT sensor can wake once every few seconds/minutes instead of continuously listening, drastically reducing energy consumption.

TWT is critical for enabling large-scale IoT deployments over Wi-Fi without degrading network performance.
