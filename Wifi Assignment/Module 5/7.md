# Multi-Link Operation (MLO) in Wi-Fi 7

Multi-Link Operation (MLO) is a key feature in 802.11be (Wi-Fi 7) that allows a device to use **multiple frequency bands or channels simultaneously** (e.g., 5 GHz + 6 GHz).

Concept:

* A single logical connection is established across multiple links
* Data can be transmitted over multiple radios/channels in parallel
* Links can be used for aggregation or redundancy

Impact on throughput:

* **Higher aggregate throughput** by combining bandwidth from multiple links
* Better utilization of available spectrum

Impact on latency:

* **Reduced latency** by dynamically selecting the least congested link
* Supports load balancing and packet-level scheduling
* Improves reliability via link redundancy (failover)

MLO effectively removes the limitation of single-link communication, enabling parallelism and more deterministic performance.
