# Role of Pairwise Master Key (PMK) in 4-Way Handshake

The Pairwise Master Key (PMK) is the root key used to derive session-specific encryption keys during the 4-way handshake.

How PMK is obtained:

* In WPA2-Personal → derived from Pre-Shared Key (PSK)
* In WPA2-Enterprise → generated via 802.1X/EAP authentication

Role in handshake:

* PMK is **not transmitted over the air**
* Used along with:

  * ANonce (from AP)
  * SNonce (from client)
  * MAC addresses
* These inputs generate the **Pairwise Transient Key (PTK)**

PTK components:

* Encryption key (for data confidentiality)
* MIC key (for integrity)
* Key confirmation key

Purpose:

* Ensures both AP and client share the same secret
* Enables secure key derivation without exposing PMK
* Forms the basis for secure communication

Thus, PMK acts as the **foundation of trust** in WPA2/WPA3 security.
