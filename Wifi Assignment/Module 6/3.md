# WEP vs WPA vs WPA2 vs WPA3

Wi-Fi security protocols have evolved to address weaknesses and improve protection.

WEP (Wired Equivalent Privacy)

* Uses RC4 encryption
* Weak key management and vulnerable to attacks
* Easily breakable; obsolete

WPA (Wi-Fi Protected Access)

* Introduced as a temporary fix for WEP
* Uses TKIP (Temporal Key Integrity Protocol)
* Improved security but still vulnerable

WPA2

* Uses AES-based CCMP encryption
* Strong and widely adopted
* Supports both PSK (personal) and 802.1X (enterprise)

WPA3

* Latest standard with enhanced security
* Uses SAE (Simultaneous Authentication of Equals) instead of PSK
* Provides forward secrecy and protection against brute-force attacks
* Improved encryption and security for open networks (OWE)

Comparison:

| Feature    | WEP       | WPA        | WPA2        | WPA3                   |
| ---------- | --------- | ---------- | ----------- | ---------------------- |
| Encryption | RC4       | TKIP       | AES-CCMP    | AES + stronger methods |
| Security   | Very weak | Weak       | Strong      | Very strong            |
| Status     | Obsolete  | Deprecated | Widely used | Modern standard        |

Overall:

* WEP/WPA → insecure
* WPA2 → baseline secure
* WPA3 → current best practice
