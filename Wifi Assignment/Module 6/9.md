# Problem Solved by 802.1X

802.1X solves the problem of **secure and scalable network access control**.

Issues with pre-shared key (PSK):

* Same password shared by all users
* Difficult to manage in large networks
* No user-level accountability
* High risk if key is leaked

802.1X solution:

* Provides **per-user authentication** using credentials (username/password, certificates)
* Integrates with backend authentication servers (e.g., RADIUS)
* Enables dynamic key generation per session

Thus, 802.1X replaces shared-key access with **individual, controlled, and auditable authentication**.
