# Pillars of Wi-Fi Security

Wi-Fi security is built on three core pillars: **Authentication, Encryption, and Integrity**.

1. Authentication
   Ensures that only authorized users/devices can connect to the network. Methods include Pre-Shared Key (PSK) and enterprise authentication (802.1X/EAP).

2. Encryption (Confidentiality)
   Protects data by converting it into an unreadable format during transmission. Prevents eavesdropping by unauthorized entities.

3. Integrity
   Ensures that data is not altered during transmission. Mechanisms like Message Integrity Codes (MIC) verify that packets are not tampered with.

Together, these pillars ensure secure access, confidentiality of data, and protection against tampering or replay attacks.
