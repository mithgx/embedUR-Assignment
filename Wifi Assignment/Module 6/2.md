# Authentication vs Encryption in Wi-Fi Security

Authentication and encryption serve different purposes in Wi-Fi security.

Authentication

* Verifies the identity of a user or device before allowing network access
* Examples: PSK (password-based), 802.1X with EAP
* Happens during connection setup

Encryption

* Protects the actual data transmitted over the network
* Converts plaintext into ciphertext using cryptographic algorithms
* Happens after successful authentication

Key difference:

* Authentication → “Who are you?”
* Encryption → “Protect the data you send”

Both are required for a secure Wi-Fi network; authentication controls access, while encryption protects communication.
