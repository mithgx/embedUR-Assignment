# Mutual Authentication in 4-Way Handshake

The 4-way handshake ensures mutual authentication by verifying that both the client (supplicant) and Access Point (authenticator) possess the same **Pairwise Master Key (PMK)** without transmitting it.

Mechanism:

* AP sends **ANonce** → client uses it to derive PTK
* Client responds with **SNonce + MIC**, proving it can compute PTK
* AP independently computes PTK and verifies MIC
* AP sends **GTK encrypted with PTK + MIC**, proving its identity
* Client verifies MIC and installs keys

Mutual authentication is achieved because:

* Client proves knowledge of PMK (Message 2)
* AP proves knowledge of PMK (Message 3)

If either side cannot compute correct keys, MIC validation fails and the handshake is aborted.
