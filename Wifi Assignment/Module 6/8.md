# Effect of Wrong Passphrase in 4-Way Handshake

If an incorrect passphrase is used, the client derives an incorrect **PMK**, which leads to incorrect PTK generation.

Consequences:

* MIC (Message Integrity Code) mismatch occurs during handshake
* AP fails to validate client’s Message 2
* Handshake fails and connection is not established

Observable behavior:

* Repeated authentication attempts
* Connection failure or disconnect loop
* Logs may show "MIC failure" or "invalid key"

No data communication starts because secure keys are never successfully established.
