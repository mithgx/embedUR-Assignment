# Why WEP is Considered Insecure

WEP (Wired Equivalent Privacy) is considered insecure due to fundamental design flaws in its encryption and key management.

Key issues:

* **Weak IV (Initialization Vector)**
  Uses a 24-bit IV which repeats frequently, making it vulnerable to statistical attacks.

* **RC4 Vulnerabilities**
  Improper use of RC4 stream cipher allows attackers to recover keys using captured packets.

* **Static Key Usage**
  Same key is shared among all users and rarely changed, increasing exposure.

* **No Strong Integrity Protection**
  Uses CRC-32 for integrity, which is not cryptographically secure and can be manipulated.

* **Easily Crackable**
  Tools can recover WEP keys within minutes using passive sniffing.

Due to these flaws, WEP is obsolete and should never be used in modern networks.
