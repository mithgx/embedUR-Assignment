# OSI Layer for Wi-Fi

Wi-Fi, defined under IEEE 802.11 standards, operates primarily in the Physical Layer (Layer 1) and Data Link Layer (Layer 2) of the OSI model.

The Physical layer is responsible for radio transmission, including frequency bands (2.4 GHz, 5 GHz, 6 GHz), modulation, and signal encoding. The Data Link layer, specifically the MAC sublayer, handles frame structure, MAC addressing, medium access control (CSMA/CA), and retransmissions.

Wi-Fi does not directly function at higher layers like Network (IP) or Transport (TCP), but it enables those protocols to operate over wireless communication.
