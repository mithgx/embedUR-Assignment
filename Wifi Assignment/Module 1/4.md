# Functionalities of a Wi-Fi Access Point

A Wi-Fi Access Point (AP) connects wireless clients to a wired network and acts as a central communication node.

Its core functions include broadcasting SSID, managing client association and authentication, and forwarding data between wireless and wired interfaces. It also enforces security mechanisms such as WPA2/WPA3 and controls medium access using CSMA/CA.

Modern APs support advanced features like band steering, load balancing, and Quality of Service (QoS) to improve network efficiency and user experience.
