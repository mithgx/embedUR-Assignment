# BSS and ESS

A Basic Service Set (BSS) is the fundamental unit of a Wi-Fi network. It consists of one Access Point (AP) and its associated client devices. Each BSS is identified by a BSSID, which is typically the MAC address of the AP.

An Extended Service Set (ESS) is formed by multiple BSSs interconnected through a distribution system (usually a wired network). All APs share the same SSID, allowing seamless roaming for users between access points without disconnection.

ESS is commonly used in enterprise and campus environments.
