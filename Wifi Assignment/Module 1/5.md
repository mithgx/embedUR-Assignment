# Bridge Mode vs Repeater Mode

Bridge mode connects two network segments at Layer 2. It forwards frames between networks without creating a new subnet, allowing devices to remain in the same network. It is typically used to extend wired networks or connect LAN segments wirelessly.

Repeater mode extends Wi-Fi coverage by receiving and retransmitting wireless signals. It connects wirelessly to an existing access point and rebroadcasts the signal to cover a larger area.

However, repeaters usually reduce throughput due to retransmission overhead, whereas bridge mode maintains better performance.
