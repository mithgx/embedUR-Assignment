# Wi-Fi Backhaul Types and Example

Wi-Fi backhaul refers to the connection between the access network and the internet.

Common types include:

* Fiber (FTTH) – High speed, low latency
* DSL (Telephone line-based)
* Cable broadband
* Cellular (4G/5G)
* Wireless point-to-point links

Example (typical home/college setup):
Most home networks use fiber-based broadband (FTTH), providing speeds from 100 Mbps to 1 Gbps with low latency and high reliability. The modem/ONT connects to a Wi-Fi router which distributes connectivity wirelessly.

Backhaul properties include bandwidth, latency, reliability, and medium type (wired/wireless).
