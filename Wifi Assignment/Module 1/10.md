# Wi-Fi Topologies and Use Cases

Wi-Fi networks can be deployed in different topologies depending on the use case:

1. Infrastructure Mode
   Uses Access Points to connect clients. Common in homes, offices, and enterprises.

2. Ad-hoc Mode (IBSS)
   Devices communicate directly without an AP. Used for temporary or peer-to-peer connections.

3. Mesh Topology
   Multiple nodes interconnect dynamically to provide wide coverage. Used in smart homes and large campuses.

4. Point-to-Point (P2P)
   Direct wireless link between two locations. Used for building-to-building connectivity.

5. Point-to-Multipoint
   One central AP connects to multiple clients. Used in ISP distribution networks.

Each topology is selected based on coverage requirements, scalability, and network architecture.
